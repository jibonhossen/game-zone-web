# Fast Gaming BD Web Domain Context

## Ubiquitous Language

**Match Mode**:
The specific game variant or format being played (e.g. Battle Royale Solo/Duo/Squad, Clash Squad 4v4, Ludo 1v1).
*Avoid*: Game Format, Game Type

**Mode Match Number**:
The sequence number representing the count of matches of a specific Match Mode.
*Avoid*: Match Id, Game Number

**Global Match Number**:
The system-wide total count of matches created across all Match Modes.
*Avoid*: Match Number, Total Matches

**Room Credentials**:
The private Room ID and Password provided to joined players to access the internal game lobby (Free Fire / PUBG Mobile).
*Avoid*: Room Key, Passcode

**Fair Play & Anti-Cheat**:
The operational directive prohibiting emulators, third-party scripts, team-teaming, or account sharing in competitive mobile matches.
*Avoid*: Anti-Hacking, Cheat Protection

**Wallet Withdrawal**:
Instant monetary payout of accumulated match prize winnings directly to local MFS services (bKash, Nagad, Rocket).
*Avoid*: Cash Out, Bank Transfer

**Custom Modal**:
An overlay dialog surface designed for detailed text, documents, rules, or job application forms, matching the brand's feature-card design system.
*Avoid*: Pop-up, Alert Prompt, Dialog Box
